# AtlasTrip React

React/Vite conversion of the original AtlasTrip HTML template.

## Included pages
- `/` — Home
- `/about` — About Us
- `/contact` — Contact Us

Only these three original site pages are exposed as React routes. Their original markup, assets, styles, and legacy interactive JavaScript are retained so the behavior stays aligned with the source template.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
